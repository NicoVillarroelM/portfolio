## 📖 Sobre el Proyecto

Portfolio web personal diseñado bajo el concepto de **ficha tipográfica / espécimen editorial impreso** (*Typographic Specimen*), inspirado en pruebas de imprenta tradicionales (marcas de corte, guías de registro, reglas de perforación, escala tipográfica en PT interactiva con el scroll).

Sirve como demostración directa de oficio, atención al detalle y capacidad técnica en el desarrollo web contemporáneo.

### ✨ Características Principales
* 🎨 **Concepto Editorial Distintivo:** Sistema visual con tokens semánticos de diseño (`--paper`, `--ink`, `--vermilion`), marcas de corte y micro-interacciones.
* 🌓 **Modo Oscuro / Claro:** Transición suave y adaptativa con persistencia de preferencia de tema.
* 🌐 **100% Bilingüe (Español / Inglés):** Internacionalización completa con `i18next` y detección automática de idioma.
* 🎭 **Animaciones con Propósito:**
  * Variación dinámica de peso y ancho tipográfico en vivo mediante *scroll progress* en el Hero.
  * Tarjetas de proyectos con giro 3D (*flip card*) para ver ficha técnica y enlaces.
* 📱 **Completamente Responsive:** Optimizado con Tailwind CSS v4 para navegación táctil y de escritorio.
* 📄 **Acceso Directo a CV:** Descarga y previsualización de currículum actualizado en un clic.

## 💻 Instalación y Desarrollo Local

### Requisitos previos
* [Node.js](https://nodejs.org/) (versión 20 o superior recomendada)
* [pnpm](https://pnpm.io/) (versión 9 o superior)

### Pasos

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/NicoVillarroelM/portfolio.git
   cd portfolio
   ```

2. **Instalar dependencias:**
   ```bash
   pnpm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   pnpm run dev
   ```
   Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

4. **Compilar para producción:**
   ```bash
   pnpm run build
   ```

5. **Verificar calidad de código:**
   ```bash
   pnpm run lint
   ```
