```
🚀 Descripción
Portfolio personal que muestra mis habilidades como desarrollador frontend, con un diseño moderno, animaciones y experiencia de usuario. Desarrollado con React, TypeScript y Tailwind CSS, incluye efectos de animación con Framer Motion y un diseño completamente responsive.
```

```
✨ Características
🎨 Diseño Moderno: Interface limpia y profesional con modo oscuro/claro
📱 Completamente Responsive: Optimizado para dispositivos móviles, tablets y desktop
🎭 Animaciones Fluidas: Efectos typewriter, cursor personalizado y transiciones suaves
⚡ Performance Optimizado: Carga rápida y experiencia de usuario fluida
🎯 Cursor Personalizado: Efectos magnéticos e interacciones avanzadas
📄 CV Descargable: Acceso directo a mi currículum actualizado
```

```
🛠️ Tecnologías
Frontend

React 18+ - Biblioteca principal
TypeScript - Tipado estático
Tailwind CSS - Estilos y diseño responsive
Framer Motion - Animaciones y transiciones
```
